How the ranking works

Every row is a protocol the snapshot records with no token, and none is a wrapped, staked or bridged product of a token that already trades, a centralised exchange, or a versioned copy. The board holds all 40 of the snapshot's watchlist protocols, plus every other eligible one.

implied value = TVL × category multiple × growth factor × age factor × chain factor

  • Category multiple — the median market-cap-to-TVL ratio of the tokened protocols in the same category, computed from this snapshot. A category with fewer than four tokened comparables uses the global median.
  • Growth factor — the protocol's seven-day TVL change, counted at half weight and clamped to −40%…+80%, so one wild week cannot set the price.
  • Age factor — how long the protocol has run with no token, rising from 0.75 toward 1.00 and saturating after about a year.
  • Chain factor — 3% per chain it runs on, up to ten chains.

Implied values are this radar's own claim from the snapshot's figures, never a prediction that a token will be issued or what it will trade at. “Records no token” means the snapshot records none; a protocol may still have one its DefiLlama record does not carry.
